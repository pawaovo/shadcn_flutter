## Public interface and state ownership

All public types are package-owned models or Flutter/Dart types. No public
API exposes `shadcn_flutter` types. The host owns accepted business data,
network/file/microphone integrations, record mutation, workflow execution,
chart data, and document persistence. The package contains no source autoplay,
canned AI response, synthetic token transport, or application backend.

| Module | Implemented boundary and interaction |
|---|---|
| Prompt Bar | Stable `composerId`, rounded/pill/tall composition, local draft and attachment entries, lazy `@`/`/` suggestions, host-controlled model and source connection state, host send/attach/connect/dictate/stop-dictation callbacks |
| Diff Table | Stable proposal/row/column IDs, immutable before/after maps, inferred added/removed/modified/unchanged meaning, local inclusion across bounded pages, immutable included-ID set sent to asynchronous `onApply` |
| Records Table | Typed columns/property configuration/tools/cells/rows, cached local search/sort, row selection, pin/hide/width, lazy viewport, property/add drafts, host save/add/run/cell callbacks, host-controlled accepted values |
| Sidebar Nav | Workspaces, primary destinations, searchable lazy recents, new chat/footer/workspace actions, host-controlled selected IDs, local drawer/rail/expanded presentation and focus/search state |
| Flowchart | Validated host-controlled DAG, typed node/edge/condition/field/option data, complete edit proposals, measured connectors, bounded pan/zoom, drag and keyboard moves, editable ordered-step alternative |
| Insight Cards | Controlled page/metric/segment selection, typed comparison/anomaly/allocation charts, local point inspection and full-data disclosure, private vector rendering of exact host values |
| Selection Actions | Actual read-only native Flutter selection, exact UTF-16 request range and source text, preset/custom request, replacement/explanation result, retry/keep/discard, explicit host application of a typed edit |

Prompt, Diff, Records, and Selection external-action failures are normalized
through `BeautifulUiScope.onFailure` under the `prompt`, `diff`, `records`,
and `selection` operations. Clipboard failures use the shared `clipboard`
operation. Identity and meaningful input/configuration changes invalidate
obsolete local completion state; equivalent snapshots and recreated callback
closures do not by themselves accept new host data.

Selection Actions uses native read-only `EditableText`, platform selection
gestures, guarded clipboard handling, and a selection-anchored toolbar. The
same actions remain available in an in-flow responsive preview. An edit
contains its original `request` and `replacement`; `request.baseText`,
`request.selection`, and `request.selectedText` allow host conflict checks,
and `updatedText` computes the exact proposed document. Keeping a suggestion
invokes `onApply`; it does not mutate host text internally.

## Source scope and adaptive presentations

The source registry JSON was inspected from a checkout pinned to the source
commit above. Exact embedded TSX/CSS paths and implemented Dart destinations
are recorded in `legal/component_provenance.yaml`. P3 introduces no source npm
runtime dependency. Commercial Central Icons, source logos, `glimm`, `liveline`,
`iconoir-react`, fabricated demo records, and scripted results remain outside
the distributable package.

- Prompt wraps compact controls and preserves the draft around viewport and
  IME changes. A source or command suggestion is a real action; source
  connection, file selection, and dictation require host callbacks.
- Diff uses compact change cards and expanded before/after fields. Explicit
  text and Semantics retain old/new meaning independently of red/green color.
- Records uses compact cards/details and an expanded horizontal grid with a
  bounded lazy vertical viewport. Property and width controls have explicit
  keyboard/touch operations. Arbitrary spreadsheet editing and formulas are
  outside this component's contract.
- Sidebar uses a compact inline drawer, medium rail, and expanded sidebar.
  An override supports narrow lanes in larger pages. The default expanded
  width is 288dp, rail width 64dp, and bounded height 600dp.
- Flowchart offers editable ordered steps on compact constraints. Expanded
  canvas editing includes pan, 1–2× zoom, and node movement; controls do not
  shrink below their baseline targets. Edge creation and graph execution are
  outside the public editing contract.
- Insights stacks or pairs prose and charts, uses marker/dash distinctions
  beyond color, and exposes every chart's exact observations through text.
- Selection keeps native text gestures and a bounded document viewport,
  supplementing its anchored toolbar with the in-flow preview. Rich-text
  editing and synthetic streaming are outside the plain-text contract.
